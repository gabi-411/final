# SDU Freshman

PWA для первокурсников SDU: карта кампуса, расписание, отзывы о преподавателях и FAQ.
Проект по курсу INF 106 (Introduction to ICT and Computer Systems), Track 2 — Software Development, тема **S4: Mobile app prototype**.

> Карта — реальная схема кампуса (`campus-map.jpg`), зоны и метки заданы координатами в `data.js`. Расписание в `data.js` — пример, замените своим. Названия объектов, определённых по иконкам (Red Canteen, H Canteen, кофейня, Support), проверьте и поправьте.

## Возможности
- 🗺️ Карта «как Google Maps / 2GIS» для кампуса:
  - pan и zoom пальцами (pinch, перетаскивание, двойной тап), колесом мыши и кнопками +/−. Сделано на нативных Pointer Events, DOM и SVG (без библиотек);
  - кликабельные блоки A–H, метки объектов (Библиотека, Wi-Fi, Info, гардероб, столовые, «бочки», зона отдыха, медпункт, Support), поиск аудиторий (G101, B202), этажи 1 / 2 / 3A / 3B / 4, красная подсветка;
  - **⌖ «Где я?»**: синяя точка по GPS, круг точности, конус направления по компасу, **🎯** «центрировать и следовать за мной»;
  - **📍 «Я здесь»**: отметить себя тапом по карте или выбрать объект, блок или аудиторию из списка (внутри здания GPS неточен);
  - **🧭 маршрут**: линия на карте от вашего положения до цели, расстояние в метрах, время пешком, пошаговая инструкция, переход между этажами через лестницу.
- 🎓 Мой SDU: ссылки на my.sdu.edu.kz и moodle.sdu.edu.kz, расписание Пн–Пт с подсветкой сегодняшнего дня, добавление/удаление пар (localStorage), кнопка «Найти на карте».
- ⭐ Отзывы: review.javazhan.tech во встроенном окне, запасной вариант при запрете встраивания или отсутствии интернета.
- ❓ FAQ: аккордеон, поиск, разговорник сленга.
- 📲 PWA: manifest, service worker, офлайн-режим, кнопка «Установить», подсказка для iPhone.
- Приложение не собирает логины и пароли.

## Запуск локально
Service worker работает только на `localhost` или HTTPS, поэтому открывайте через сервер:
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000

## Тесты
```bash
node tests.js        # в терминале
```
или откройте `tests.html` в браузере. Тесты покрывают в том числе аффинное преобразование (туда-обратно < 1 px, шум, вырожденные точки), «вне кампуса», Дейкстру (кратчайший путь, недостижимая цель), привязку к ближайшему узлу и ребру, маршруты между этажами и связность графа.

## Деплой на GitHub Pages
1. Создайте репозиторий на GitHub (например, `sdu-freshman`).
2. Загрузите все файлы в корень репозитория (кнопка *Add file → Upload files* или `git push`).
3. *Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save*.
4. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/sdu-freshman/`. Это и есть live demo.

## Как поменять карту
Все зоны и метки — в `data.js`: `ZONES` (контуры блоков) и `PLACES` (метки). Координаты — в пикселях картинки `campus-map.jpg` (739×1376). Узнать координаты любой точки проще всего в `calibrate.html`: тап по карте показывает x, y. Чтобы добавить блок I, допишите `ZONES.I`, добавьте `"I"` в `ROOM_BLOCKS` и запись `I: { entry, stairs }` в `ZONE_NODES`. После правок файлов увеличьте номер версии в `sw.js` (`CACHE_NAME`), иначе телефон покажет старый кэш.

## Как работает геолокация
1. Кнопка **⌖** запускает `navigator.geolocation.watchPosition` с `enableHighAccuracy: true`. Браузер спросит разрешение.
2. Координаты переводятся в пиксели картинки **аффинным преобразованием** (`createGeoTransform` в `logic.js`):
   - lat/lng переводятся в метры от центра контрольных точек (локальная проекция);
   - по 3+ контрольным точкам `{lat, lng, x, y}` из `GEO_CONTROL_POINTS` (`data.js`) методом наименьших квадратов считается матрица `x = a·u + b·v + c`, `y = d·u + e·v + f`;
   - `convert(lat, lng) → {x, y}` и обратная `invert(x, y) → {lat, lng}`. Заодно считаются ошибка на каждой точке, масштаб м/px и угол севера на картинке (он нужен для конуса направления).
3. Синяя точка рисуется с кругом точности: радиус = `accuracy` (м) / `METERS_PER_PIXEL`. Если точка дальше `GEO_MARGIN_PX` от краёв картинки, показывается «Вы вне кампуса», и точка не рисуется.
4. Направление взгляда берётся из `DeviceOrientationEvent` (на iPhone `webkitCompassHeading` после `requestPermission()` по нажатию ⌖, на Android `deviceorientationabsolute`). Если компаса нет, конус просто не показывается.
5. **Приватность:** координаты нигде не хранятся и никуда не отправляются. Сразу после получения они переводятся в пиксели и живут только в памяти страницы. Внешних API карт и ключей нет.
6. Геолокация требует **HTTPS** (GitHub Pages подходит) или `localhost`. При запрете или отсутствии GPS показывается понятное сообщение, остальная карта работает.

Положение берётся либо из GPS, либо вручную. Точка, поставленная через **📍 «Я здесь»** (тап по карте или выбор из списка), важнее GPS, пока не нажата «Использовать GPS». Под картой всегда видно, откуда взято положение: «по GPS (±N м)» или «вручную».

## Как откалибровать контрольные точки (≈10 минут на месте)
1. Задеплойте сайт и откройте на телефоне `https://<логин>.github.io/sdu-freshman/calibrate.html`.
2. Встаньте в узнаваемое место **у края здания, лучше снаружи** (углы корпуса, главный вход в Block C, вход у Block G, торец Block H). Внутри здания GPS ошибается на 10–50 м.
3. Нажмите «Включить GPS» и подождите, пока точность станет ≤ 5–10 м. Страница усредняет замеры за 15 секунд.
4. Тапните это же место на карте и нажмите «Добавить контрольную точку».
5. Повторите для 4–6 точек **по разным краям** кампуса, не на одной прямой.
6. Посмотрите столбец «ошибка, px»: точку с большой ошибкой удалите и перемерьте. Нажмите «Копировать для data.js» и замените блок `GEO_CONTROL_POINTS` в `data.js`. Там же поставьте `GEO_CALIBRATED = true` и подставьте оценку `METERS_PER_PIXEL`.
7. Увеличьте `CACHE_NAME` в `sw.js` и задеплойте.

## Как менять граф маршрутов
Граф лежит в `data.js`:
- `NODES`: `{ id, x, y, floor, area, stairs? }`. `area` — название участка, из него собирается текстовая инструкция («Главный коридор», «Крыло Block F»…). `stairs: true` — лестница.
- `EDGES`: `["id1", "id2"]`. Вес (расстояние) считается сам по координатам. Свой вес задаётся третьим элементом: `["a", "b", 250]`. Все проходы двусторонние.
- `ZONE_NODES`: для каждого блока узел входа в крыло (`entry`) и лестница (`stairs`).

Чтобы добавить узел, откройте `calibrate.html`, включите «показать граф», тапните место и нажмите «Копировать как узел NODES». Вставьте строку в `NODES`, поменяйте `id`/`area` и добавьте ребро в `EDGES`. Затем `node tests.js`: тесты проверят, что все узлы достижимы, лежат на картинке и что к каждому объекту есть путь.

Как строится маршрут: положение пользователя проецируется на ближайший коридор (ребро графа), дальше алгоритм Дейкстры (`shortestPath`) ищет путь до цели. Для объекта цель — ближайший к метке узел, для аудитории — вход в крыло её блока. Если этаж цели отличается от выбранного «Я на этаже», путь проходит через лестницу (блока цели при подъёме, ближайшую при спуске), и в инструкции появляется «поднимитесь/спуститесь на N этаж». Время = расстояние / `WALK_SPEED_MPS` + `SECONDS_PER_FLOOR` за этаж.

## Ограничения
- **Точность GPS внутри зданий низкая** (10–50 м, точка может «прыгать»). Поэтому есть «Я здесь», а при точности хуже 30 м приложение советует отметить себя вручную.
- **Этаж GPS не определяет**: его выбирают кнопками «Я на этаже». Картинка — план 1-го этажа, маршрут по верхним этажам рисуется по той же схеме.
- Пока в `data.js` стоят заглушки `GEO_CONTROL_POINTS` (`GEO_CALIBRATED = false`), синяя точка неточная, и приложение предупреждает об этом.
- `METERS_PER_PIXEL` — оценка, от неё зависят метры и минуты.
- Компас есть не на всех устройствах. На iPhone нужно разрешение, на ПК компаса нет.


## Интерактивность карты и адаптивная карточка
- Двигайте карту пальцем или мышью; pinch-to-zoom, двойное нажатие, колесо мыши и кнопки +/− работают без сторонних библиотек.
- Нажмите на корпус A–H или круглый маркер объекта, чтобы выбрать место.
- На телефоне информационная карточка открывается как нижняя панель (bottom sheet). Закройте кнопкой ×, клавишей Esc или проведите вниз по верхней ручке. На ПК карточка находится в правой боковой колонке.
- Карта, маркеры, поиск и маршруты работают офлайн через service worker; сторонние UI-библиотеки не добавлялись.
- GPS работает с разрешения пользователя на HTTPS/localhost. Внутри здания точность зависит от устройства; позиционирование относительно схемы кампуса требует проверки контрольных точек в `data.js` и калибровки.
- После публикации обновите страницу приложения, чтобы service worker заменил старый кэш.

## Нативное управление картой
- **Один палец / левая кнопка мыши:** перемещение карты (`pointerdown`, `pointermove`, `pointerup`).
- **Два пальца:** pinch-to-zoom (расстояние через `Math.hypot`, масштабирование около центра жеста).
- **Мышь:** колесо приближает вокруг курсора; двойной клик приближает; кнопки +/−.
- **Карточка:** в мобильном браузере появляется снизу (bottom sheet), на компьютере — в боковой колонке.
- `touch-action: none` действует только на самой карте, поэтому на остальной странице прокрутка сохраняется.
- Для PWA версия кэша поднята в `sw.js`; после обновления перезагрузите приложение с интернетом.
- GPS-привязка в `data.js` остаётся примерной до физической калибровки.
